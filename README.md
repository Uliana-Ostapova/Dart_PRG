## RPG-битва
Консольная игра в которой персонажи сражаются друг с другом. В игре есть три класса персонажей: воин, маг и лучник. Каждый персонаж обладает собственными характеристиками и особенностями атаки.

## Ответы на вопросы
1.	**Что такое абстрактный класс? Почему нельзя написать `Character()` напрямую?**
Абстрактный класс - класс, который служит шаблоном для других классов и не может быть создан на прямую. В нём могут находится общие поля, методы и абстрактные методы. Создать объект `Character()` нельзя, потому что он объявлен с ключевым словом `abstract`.

2.	**Зачем нужен `super` в конструкторе наследника? Что будет если его убрать?**
`super` используется для обращения к родительскому классу и вызова его конструктора. С его помощью наследник передаёт родителю необходимые значения. Если убрать `super` Dart попытается автоматически вызвать конструктор родителя без параметров и возникнет ошибка компиляции.

3.	**В чём разница между `@override` у `attack()` в `Warrior` и `takeDamage()` в `Warrior`? Почему второй переопределяет метод который уже имеет реализацию в родителе?**
`attack()` переопределяется потому что в родительском классе `Character` он объявлен как абстрактный и не имеет реализации. Поэтому каждый наследник должен самостоятельно определить его работу. `takeDamage()` уже имеет реализацию в родительском классе. Воин переопределяет его чтобы добавить учёт брони, которая уменьшает получаемый урон. После уменьшения урона вызывается родительский класс.

4.	**Функция `fight(Character a, Character b)` не знает кто реально придёт — `Warrior`, `Mage` или `Archer`. Как называется эта концепция и где вы её уже видели во `Flutter`?**
Эта концепция называется полиморфизмом. Она позволяет переменной родительского типа хранить объект любого дочернего класса. Во Flutter такой принцип используется при работе с виджетами. Метод `build` работает с типом `Widget`, поэтому может возвращать разные виды виджетов.

5.	**Что означает `_random` с нижним подчёркиванием в классе `Character`?**
Нижнее подчёркивание перед `_random` обозначает приватное поле. Такие поля доступны только внутри библиотеки в которой они объявлены.
